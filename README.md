# 社区避难点启用采录台

离线虚构的避难点资源、灾情启用与分流、人员入离及配给三套业务账。设施失效会缩减实际床位并为已收容者生成待转移决定；矛盾启用令会冻结新增收容；跨点重复入场和重复领物资会拒绝。原始文件字节、事件哈希与裁定版本持久化在 SQLite。

```powershell
python -m pip install . --no-deps --no-build-isolation
python -m shelterledger demo --db demo.sqlite
python -m shelterledger audit --db demo.sqlite
python -m unittest discover -s tests -v
```

三个独立入口是 `shelter-import`、`activation-import`、`intake-import`，用 `--file fixtures/*-ok.json` 和对应 `*-bad.json`。`report` 输出资源容量、事件令、目的地、入离、配给及转移记录；`audit` 从原始文件重放到新库逐表核对。所有身份、签章和社区名称为合成数据，首版不连真实指挥系统。

## 离线服务工时台

`crew-import` 录入两桌十分钟志愿服务单与现场取证原件。表单分钟只作报工摘要原样保留，工时证书按已证明的同时工作总量签发，单位为实际贡献的人分钟，不签个人额度：每个实际贡献者同一时点最多计一分钟，两个同时工作的不同人各计一分钟。

同一报工合同允许两条互斥的取证路线，二者可签发同一类型的班组工时证书，但依据、覆盖时段和对独立人手的根据不同：

- 路线 A（工牌）：当班作用域内的实物工牌新发牌锚点，加两桌共同见证的转发关系，把桌上的匿名本地号映射到实物凭据；只有本地号不同而无新发牌锚，不得推断为两个人，也不要求两桌物理隔离。两桌同指一人证 10 人分钟，两个独立锚点证 20。
- 路线 B（互斥工具位）：两台一次只容纳一人的工具位，加上覆盖全时段的独立双签同时占用观察；不需要知道谁换了号即可证 20。单签或按钮作业回执、只证明工具位移过而不能独立核验同时占用的，不能充当两人。

两条路线对同一时段都证成却互斥时，证书进入 `conflict`，给出造成不一致的最小现场见证，绝不取最高值；被后来真实工单推翻的证据标记为 `contradicted` 但原件与旧版证书全部保留。同一轮次缺少一次实际重新开始的见证（新发牌锚或时段内工位见证），相同人手不得重复计量。跨时间片的身份/工具位关系用并查集统一求解，不能逐段挑选有利解释；范围限两桌、最多三名志愿者、三段离散时段。

下一班最多补读或补签一次见证（`crew_late_action` 记额）：可取回原先独立签过的备份（`backup_retrieval`），或在工牌根证尚存时回补身份（`witness_resign`）；必须在原时段拿到的双位同时见证不能事后补作，重放也不借用另一班、另一轮的工牌或工位证明。`python -m shelterledger crew-cert --db <库> --team <班组>` 查看当前证书、缺失原件清单与下一班可分开承诺的动作及各结果对应的工时档。
